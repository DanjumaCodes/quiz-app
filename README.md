# Quiz App

A simple, responsive quiz app built with HTML, Tailwind CSS, and vanilla JavaScript. This is one of my first JavaScript projects, built while learning DOM manipulation and event handling.

## Features

- Start screen, quiz screen, and result screen
- One question at a time with multiple-choice options
- Score tracking
- Progress text and progress bar
- Answer buttons are disabled after you choose one
- Final score with a feedback message
- Restart button to play again

## Built With

- HTML
- Tailwind CSS
- JavaScript (vanilla)

## What I Learned

- Arrays of objects to store questions
- Selecting and updating elements with the DOM
- Creating elements with JavaScript
- Event listeners and state variables
- Showing and hiding screens with classes

## How to Run

1. Clone the repo:
   `git clone https://github.com/DanjumaCodes/quiz-app.git`
2. Open `index.html` in your browser.
